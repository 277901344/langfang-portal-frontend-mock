# 前端文件命名规范

1. 组件文件使用 PascalCase，例如 `UserProfile.tsx`
2. 工具函数使用 camelCase，例如 `formatDate.ts`
3. 目录使用 kebab-case，例如 `user-management/`
4. 组件名称使用 PascalCase，例如 `<PrimaryButton />`
5. Props 使用 camelCase，例如 `isLoading`, `onUserUpdate`
6. CSS 类名使用 BEM 或 CSS Modules
7. 常量使用 UPPER_SNAKE_CASE
8. TypeScript 接口使用 PascalCase
